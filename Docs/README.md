# Документация Noob Mini Generals

Эта папка — точка входа для новой сессии ИИ или нового человека в проекте. Прочитав её, можно
понять, что за игра, как она устроена, в каком она состоянии и как здесь принято работать.

## Порядок чтения

1. [`../CLAUDE.md`](../CLAUDE.md) — жёсткие правила работы (коротко, обязательно).
2. [`01-game-design.md`](01-game-design.md) — что за игра: видение, механики, принятые решения и почему.
3. [`02-architecture.md`](02-architecture.md) — как устроен код: технологии, папки, системы, масштабы.
4. [`03-roadmap.md`](03-roadmap.md) — план работ (вертикальный срез), что сделано, что дальше, отложенное.
5. [`04-problems-and-lessons.md`](04-problems-and-lessons.md) — проблемы, которые уже решались, и уроки из них.
6. [`05-workflow.md`](05-workflow.md) — как устроена работа: облачная и локальная сессии, проверка компиляции без Unity, git, общение.

Подробности по отдельным частям кода — в README рядом с кодом:
`Assets/VoxelArena/README.md` (арена) и `Assets/Gameplay/README.md` (бой).

## Состояние одной строкой (обновлять при каждом крупном шаге)

Вертикальный срез: шаги 1–3 (старт матча, экономика, строительство с полноценным UX установки)
сделаны и проверены автором в Unity. Шаги 4 (казармы, пехота, «Оборона / Атака») и 5 (стрельба
видимыми снарядами, турели, прочность, воронки, разрушение, победа и поражение по главному
зданию) сделаны, компилируются, ждут проверки в Unity. Дальше — шаг 6: простой скриптовый ИИ
противника. Точки захвата заморожены до решения автора.

Последнее обновление: 30.09.2026.

## Как поддерживать документацию

- Решение принято → запись в `01-game-design.md` (раздел «Решения») с причиной.
- Шаг сделан или план поменялся → `03-roadmap.md` и строка состояния выше.
- Нашли и починили нетривиальную проблему → `04-problems-and-lessons.md`.
- Открытый вопрос → только в одно место: геймдизайн — `01-game-design.md` («Открытые вопросы»),
  техника — `03-roadmap.md` («Отложено → Техника»). В остальных файлах — ссылка.
- Новый файл или система → `02-architecture.md` и README рядом с кодом.
